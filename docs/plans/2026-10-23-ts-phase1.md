## 为什么这样拆

- **现有 JS 必须先保持全绿**：所有新类型文件都是新增，运行时只动了 `mentions.js` 的再导出，所以 `npm test` / `npm run build` 零行为变化。
- **契约先于迁移**：Phase 2/4 把 UI 与 host 搬到 TS 时，直接对着 `schema.ts` / `rpc.ts` 改，改一个字段两边一起报错，不用事后补类型。
- **DSH 类型自持**：`dsh-types.ts` 只声明本插件用到的结构，不依赖 DSH 安装目录或源码，符合「底座不动」。
- **构建入口前向兼容**：现在还是 `index.js`；Phase 2 把入口改成 `index.tsx` 时不用再动 build 脚本。
